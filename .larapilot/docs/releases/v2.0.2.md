# v2.0.2 — Security follow-ups for 2.0.1

Three security fixes: a safer starting configuration for a new host, a protected Garmin import
review, and a way to sign out.

## Fixed

- **A new host starts with safe settings.** The example settings shipped with the project now
  describe a production site: no debug pages, logs rotated daily, secure cookies only, and an
  `https` address. A library the app uses to read web requests is updated to a release that closes
  a flaw where a crafted request could tie up the host. Local development uses the overrides listed
  in the README.
- **The Garmin import review can no longer be used to overload the site, and no page can be
  framed.** Reloading the review of an uploaded file is limited like the upload itself, and a
  reload reuses the review it already prepared while nothing has changed. Every page now tells the
  browser it may not be shown inside another site, so no one can trick a visitor into pressing the
  review's buttons through a disguised page.
- **You can sign out, and a device no longer stays signed in for a year.** When signed in, the
  dashboard shows "Sign out" next to the Garmin import link. Signing in no longer leaves a
  long-lived cookie behind: a session now ends when it expires or when you sign out. Signing out
  keeps the Strava connection, so the nightly sync carries on. A browser signed in before this
  version should sign out once to drop its old long-lived cookie.
