# v2.0.0 — v2.0

Your running heatmap now goes back in time, shows how your weekly distance is trending, and tells
you more about every run. The Garmin import is open to everyone and keeps runs of any age.

## Added

- **Browse past weeks.** "Previous 4 weeks" and "Next 4 weeks" move the 16-week heatmap through
  your history. The dates shown are always written above the grid, and each period has its own
  link, so a reload or a shared link opens the same weeks.
- **Weekly distance chart** beside the heatmap: one bar per week with a 4-week average line, a
  "partial" marker on the week in progress, and every week's figures listed underneath. It follows
  the weeks you are looking at, and sits under the grid on a phone.
- **Run details on every day.** Tap, click, or press Enter on a day with runs to see each run's
  name, distance, moving time, average pace, total ascent and average heart rate, with a link to
  the run on Strava when it came from there. Runs already stored gain these figures on the next
  Strava sync, and the Garmin import reads them from the file when present.

## Changed

- **The Garmin CSV import keeps runs of any age**: only runs dated in the future are skipped, and
  one import can now hold up to 5,000 runs.
- **Anyone can import a Garmin CSV**, signed in or not. On a fresh install the first import creates
  a CSV-only athlete whose heatmap the home page then shows, without needing a Strava connection.

## Fixed

- **A run on the last day of the period shown is now counted.** A run on the Sunday that ends the
  period (the bottom row of the grid), or today's run when today is a Sunday, showed as a rest day.
  It now appears in the day, the week total, the weekly chart and the colour scale.
