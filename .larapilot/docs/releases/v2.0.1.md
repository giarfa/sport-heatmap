# v2.0.1 — Fixes for 2.0.0

A security fix: a deployed site no longer carries the developer dashboard.

## Fixed

- **The developer dashboard stays off deployed sites.** The project dashboard used while building
  the app, and the AI coding tools that come with it, were installed on every host. On a host left
  with the example settings, anyone who reached it could read the Strava secret and the app key,
  download the database, or write files, without signing in. These tools are now development-only:
  a host installed with `composer install --no-dev --optimize-autoloader` does not have them, and
  every address under `/larapilot` answers "not found". The README's "Before putting this on a real
  host" section now starts with this install step and how to check it.
