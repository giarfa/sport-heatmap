# v3.0.0 — Private login

The heatmap becomes a private instance with one owner and one data source: you sign in with your
own password, and your runs come only from the Garmin Connect CSV export. Strava is gone.

**Before you upgrade: this version permanently deletes every run that came from Strava, and the
Strava tokens with it. Back up the database first.** A run you already overwrote from a Garmin CSV
is kept with all its values.

## Added

- **A sign-in page for the owner.** The first sign-in uses an empty password and then asks you to
  set one of at least 12 characters; from then on only that password signs in. Sign-in attempts are
  limited to five a minute, and a refused attempt says how long to wait.

## Changed

- **Every page is private.** A signed-out browser is sent to the sign-in page; the public read-only
  dashboard and the import for signed-out visitors no longer exist. Signing out returns to the
  sign-in page.
- **The Garmin CSV import is the only way a run enters.** A row is a conflict against any stored run
  on the same date within two minutes, and Overwrite, Skip, and apply-to-all work as before.
- **One status line.** The dashboard reads "Last import N ago" from your newest import, or "No runs
  imported yet"; there is no stale, failed, or reconnect warning anymore. With no runs, the screen
  offers only the Garmin CSV import.
- **The day detail stays on the page.** It lists name, distance, moving time, pace, ascent, and heart
  rate, with no link to an outside site.

## Removed

- The Strava connection, the nightly sync, and every sync warning.
- "Powered by Strava", the "Connect with Strava" screen, and every Strava link.

## After upgrading

- Revoke the former app at <https://www.strava.com/settings/apps>. The instance no longer stores a
  third-party token and makes no outbound request.
- The nightly task is no longer needed: the app schedules nothing.
