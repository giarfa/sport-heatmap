## Lars (security)

**No Critical/High/Medium/Low findings.** `composer audit` clean; this branch adds no new dependencies.

- **Credential leakage (exceptions/logs):** `StravaApiException` messages carry only HTTP status + rate-limit usage header, never token/body/URL. `unreachable()` chains the Guzzle `ConnectionException` but deliberately writes a fresh message instead of reusing `$previous->getMessage()`, which would have embedded the request URL. `SyncStravaActivities::handle()` logs `athlete_id` + `$exception->getMessage()` only. `EnsureFreshAccessToken` logs athlete_id + reason on refresh failure, never token values. All consistent with `.ai/rules/app.md`.
- **Authorization:** `AthleteAllowlist::allows()` does a strict `in_array` compare, fails closed on an empty list. `SyncStravaActivities::connectedAthletes()` requires `strava_athlete_id`/`strava_access_token`/`strava_refresh_token` all non-null AND allowlist membership, filtered per-user — a disconnected or de-allowlisted athlete is excluded before any Strava call. Covered by `test_an_athlete_no_longer_on_the_allowlist_is_skipped`.
- **Cross-athlete data leakage / mass assignment:** `ReconcileStravaWindow` writes and deletes exclusively through `$user->activities()` (a `HasMany`), so both `updateOrCreate` and the `whereNotIn(...)->delete()` are relation-scoped to one athlete. `Activity`'s `#[Fillable]` list excludes `user_id`.
- **SSRF / config injection:** `strava.api_base_url` and OAuth endpoints are hardcoded literals in `config/strava.php`, not `env()`-sourced — matches `.ai/rules/config.md`.
- **Untrusted DTO parsing:** `StravaActivity::fromApiPayload` validates every field (`is_numeric`/`is_string`/regex on the date, strict enum membership for sport type) before constructing typed values; malformed items return `null` and are skipped rather than reaching Eloquent.
- **Token-refresh race (`$rejectedToken`):** `EnsureFreshAccessToken::mustRefresh()` only forces a refresh when the currently-stored token still equals the one that was rejected — if another process already rotated it, the caller picks up the new token instead of forcing a second refresh. `StravaClient`'s retry callback also guards with `$refreshedOnce` so it can only trigger once per page. Both paths are covered by `StravaClientTest`.
- **`security.txt`/`SECURITY.md`:** absent, as before. Not required for this change (same verdict as US-001/US-002 — revisit at ship).
