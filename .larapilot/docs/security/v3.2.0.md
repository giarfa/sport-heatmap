**Verdict:** GO

## Summary

Deploy target unchanged: Cipi 5.7 on an Oracle Cloud ARM VM (app `heatmap`, branch `main`), reachable on its `sslip.io` hostname, Cipi basic auth off — the app's own sign-in is the only gate. No edge or WAF; Laravel log files only. Production runs v3.1.0.

v3.2.0 adds one read-only dashboard card, aerobic efficiency (US-024). No route, input, migration, secret, outbound call, or dependency changes.

- **A01 — holds.** No new route; both new reads are scoped through `$athlete->activities()`; signed out, every probed URL redirects to `/login` (Oliver, probe 1).
- **A02 — no change.**
- **A03 — holds.** The card prints only server-computed numbers, dates, and fixed copy through `{{ }}`; no stored free text is shown; `?to=` is parsed to a date and bound (Oliver, probes 2–4).
- **A04 — holds.** Pre-history windows stay uncached by design; they now cost two more indexed reads (Low).
- **A05 — no change.** Host env flags confirmed for v3.1.0: `APP_ENV=production`, `APP_DEBUG=false`. The cache allowlist grows by exactly the five new classes (Oliver, probe 5).
- **A06 — PASS.** `composer audit --no-dev`: no advisory. `vendor-audit --gate` (OSV.dev, 238 components): **PASS, nothing open or waived**.
- **A07 / A08 / A09 / A10 — no change.**

Checks run locally on the release: 794 tests, Pint, PHPStan — all pass.

## Findings

### [Low] Pre-history windows cost two more uncached reads

- **OWASP:** A04
- **Location:** `GET /?to=…` → `App\Support\Heatmap\EfficiencyRuns`
- **Risk:** owner-only, signed-in; negligible load.
- **Remediation:** none required.

### [Info] Accepted risks unchanged

- No edge or WAF on a private single-owner instance.
- `SECURITY.md` and `security.txt` deferred while the instance is private.
- `TrainingBlockSeeder` clears the owner's password when run against a local database holding real data; the production guard holds. Never seed production.

## Ship Recommendation

**GO.** No Critical, High, or Medium finding; the dependency gate passes. No migration: copy the SQLite file aside anyway, deploy, then confirm the new grid cache key (`v7`) builds the card on first load.
