# Security Assessment — v2.0.0

**Assessor:** Lars (Larapilot Security Expert) — incorporates 🎯 Oliver red-team report (`red-team-v2.0.0.md`)
**Date:** 2026-10-18
**Verdict:** NO-GO — v2.0.0 is not deployed. Remediation ships as v2.0.1, which is assessed again before deploy.

## Summary

Deploy target (decided 2026-10-17): custom VPS with Deployer, **private** (basic auth, VPN or IP allowlist), no edge or WAF, Laravel log files only.

The application code passes the OWASP review:

- OAuth state and allowlist (A01/A07)
- Escaping (A03)
- CSRF (A01)
- No SSRF (A10)
- Encrypted tokens (A02)

The release is blocked by deployment configuration (A05) and vulnerable components (A06). The dependency gate (`vendor-audit --gate`) **FAILs** with 1 Critical, 2 High and 1 Medium. `composer audit` adds CVE-2026-108082 in `symfony/http-foundation`.

## Findings

### [High] The Larapilot dashboard is a production dependency, open without sign-in when APP_ENV is not production

- **OWASP:** A05, A01
- **Location:** `composer.json:13`; `vendor/andreapollastri/larapilot/src/Services/Auth/AccessPolicy.php:53-63`; `.env.example:2`
- **Risk:** reading `.env` (APP_KEY, Strava secret), downloading a database dump, and writing files under `/larapilot/*`, all without a session.
- **Remediation (decided):** move `andreapollastri/larapilot` to `require-dev` and deploy with `composer install --no-dev` (v2.0.1).

### [Critical/High — dev only] shell-quote 1.9.0 (GHSA-pqg4-j6r4-53mv), source-map-js 1.2.1 (GHSA-68fv-2mgg-jv7q)

- **OWASP:** A06
- **Location:** `package-lock.json` (build toolchain only, never deployed)
- **Risk:** build machine only.
- **Remediation (decided):** `npm update shell-quote source-map-js` (v2.0.1).

### [Medium] symfony/http-foundation 8.1.6 — CVE-2026-108082, ReDoS via the Cache-Control header

- **OWASP:** A06
- **Location:** `composer.lock`
- **Risk:** worker exhaustion from any client that can reach the host, before routing and throttling.
- **Remediation (decided):** update to 8.1.7 or later (v2.0.1).

### [Medium] Boost becomes active with APP_DEBUG=true; unsafe `.env.example` defaults

- **OWASP:** A05, A09
- **Location:** `vendor/laravel/boost/src/BoostServiceProvider.php`; `.env.example`
- **Risk:** an unauthenticated, CSRF-exempt endpoint that writes to the logs, debug pages exposing the environment, and log files that never rotate.
- **Remediation (decided):** a production-safe `.env.example` (`APP_DEBUG=false`, `BOOST_ENABLED=false`, `LOG_STACK=daily`, `LOG_LEVEL=warning`, `SESSION_SECURE_COOKIE=true`, https `APP_URL`), with the keys listed in the README host checklist (v2.0.1).

### [Low] league/commonmark 2.10.0 — GHSA-3q6v-r5mr-hxv8, GHSA-97jj-33gv-5xf9

- **OWASP:** A06
- **Location:** `composer.lock`
- **Risk:** not reachable from the app.
- **Remediation (decided):** update to 2.10.2 or later (v2.0.1).

### [Low] The Garmin import review page has no rate limit; parsed rows are stored in the session

- **OWASP:** A04
- **Location:** `routes/web.php:44`; `app/Support/Garmin/PlanGarminImport.php`; `app/Support/Garmin/PendingGarminImport.php`
- **Risk:** CPU and disk exhaustion by a guest.
- **Remediation (decided):** throttle the review route and bound the per-request planning cost (v2.0.1).

### [Low] No security headers; the import confirmation page can be framed

- **OWASP:** A05
- **Location:** `bootstrap/app.php`
- **Risk:** a trick click on "Overwrite" from a page that frames the import.
- **Remediation (decided):** `frame-ancestors 'none'`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: same-origin`, and HSTS on HTTPS (v2.0.1).

### [Low] No sign-out; a remember-me cookie is always issued

- **OWASP:** A07
- **Location:** `app/Http/Controllers/Strava/StravaCallbackController.php:124`; `routes/web.php`
- **Risk:** a lost or shared device keeps owner access for about 400 days.
- **Remediation (decided):** a CSRF-protected logout that clears the remember cookie (v2.0.1).

### [Info] Accepted risks unchanged

These remain accepted while the instance is private:

- open Garmin import;
- fallback athlete displayed publicly;
- public heart rate;
- Strava API Agreement display clause;
- SECURITY.md and security.txt deferred.

Also noted: the rejected athlete's grant is not revoked on Strava, and trusted proxies are not configured (correct while nginx terminates TLS on the same host).

## Ship Recommendation

**NO-GO for v2.0.0.** Deliver v2.0.1, "Fixes for 2.0.0", with every finding above, then run `/larapilot-ship` again for v2.0.1. That run repeats this gate and `vendor-audit --gate`.

Deploy prep for the custom VPS must enforce these settings in the production environment:

- `APP_ENV=production`
- `APP_DEBUG=false`
- `composer install --no-dev`
- `php artisan optimize`
- a cron entry running `schedule:run` every minute
- the SQLite file and `storage/` on persistent, non-public paths
- basic auth, VPN or an IP allowlist in front of the site
