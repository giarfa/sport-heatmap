# Security Assessment — v2.0.2

**Assessor:** Lars (Larapilot Security Expert) — incorporates 🎯 Oliver red-team report (`red-team-v2.0.2.md`)
**Date:** 2026-10-18
**Verdict:** GO

## Summary

Deploy target unchanged since v2.0.0 (decided 2026-10-17): custom VPS with Deployer, **private** (basic auth, VPN or IP allowlist), no edge or WAF, Laravel log files only.

v2.0.2 closes every finding the v2.0.1 assessment left open, Oliver re-tested each on the release tag:

- **A06 — closed.** `symfony/http-foundation` updated past CVE-2026-108082 (US-017). `composer audit`: no advisory. `vendor-audit --gate` (OSV.dev, 231 components): PASS.
- **A05/A09 — closed.** `.env.example` ships production values; a host built from it shows no debug page and writes daily logs at `warning` (US-017).
- **A04 — closed.** The Garmin import review is throttled like the upload and the confirm, ten a minute, and reuses its plan while nothing changed (US-018).
- **A05 — closed.** Every response, a 404 included, carries `frame-ancestors 'none'`, `X-Frame-Options: DENY`, `nosniff` and `Referrer-Policy: same-origin`; HSTS on HTTPS (US-018).
- **A07 — closed.** A CSRF-protected `POST /logout` ends the session; replaying it afterwards is a guest. Sign-in issues no remember-me cookie. Sign-out keeps the Strava tokens (US-019).

The rest of the v2.0.0 review stands: OAuth state and allowlist (A01/A07), escaping (A03), CSRF (A01), no SSRF (A10), encrypted tokens (A02). No migration in this release. CI checks run locally on `develop` at the release: 624 tests, Pint, Larastan, `composer audit` — all pass.

## Findings

### [Low] Recallers issued before 2.0.2 stay valid until the owner signs out once

- **OWASP:** A07
- **Location:** `app/Http/Controllers/Strava/StravaCallbackController.php:130`
- **Risk:** a lost or shared device that signed in before 2.0.2 keeps owner access for the rest of its ~400-day cookie.
- **Remediation:** after the deploy, clear `remember_token` for every user (one statement, below), or sign out once on every browser used before 2.0.2.

### [Info] Accepted risks unchanged

These remain accepted while the instance is private:

- open Garmin import;
- fallback athlete displayed publicly;
- public heart rate;
- Strava API Agreement display clause;
- SECURITY.md and security.txt deferred.

## Ship Recommendation

**GO for v2.0.2**, deployed under the same conditions as v2.0.1 on the custom VPS, plus the asset build:

- `composer install --no-dev --optimize-autoloader`, then `php artisan route:list --path=larapilot` lists no route
- `npm ci && npm run build` (the Vite manifest is not committed; without it every page is a 500)
- `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL` on https
- `LOG_STACK=daily`, `LOG_LEVEL=warning`, `SESSION_SECURE_COOKIE=true`
- `php artisan optimize` after every deploy
- a cron entry running `schedule:run` every minute
- the SQLite file and `storage/` on persistent, non-public paths
- basic auth, VPN or an IP allowlist in front of the whole site
- once, after this deploy: `php artisan tinker --execute 'App\Models\User::query()->update(["remember_token" => null]);'` — invalidates every pre-2.0.2 remember-me cookie

A public deployment re-opens this assessment: the accepted risks above are acceptable only while the instance is private.
