# Security Assessment — v3.0.0

**Assessor:** Lars (Larapilot Security Expert) — incorporates 🎯 Oliver red-team report (`red-team-v3.0.0.md`)
**Date:** 2026-10-26
**Verdict:** GO

## Summary

Deploy target: Cipi 5.7 on an Oracle Cloud ARM VM (app `heatmap`, Deployer-based), **private** behind Cipi basic auth, no edge or WAF, Laravel log files only. Production ran 2.0.2, held no users and no runs, and was suspended at assessment time.

v3.0.0 replaces the Strava OAuth identity with a single-owner password sign-in (US-020) and removes Strava entirely (US-021):

- **A01 — tightened.** Every route but `/login` and `/up` requires a session; the import routes moved behind it. Oliver: all protected routes 302 → `/login` signed out; no Strava or dev-tooling route on the `--no-dev` build.
- **A02 — tightened.** No third-party token is stored any more: the Strava token columns are dropped, not merely emptied. Passwords use the `hashed` cast.
- **A03 — no change.** CSV titles with script and event-handler payloads are escaped in the review and the day detail.
- **A04 — holds.** Sign-in throttled per username and IP (five a minute, the wait is shown); the import keeps its throttle, 5 MB limit (413 at 6 MB), and session binding.
- **A05 — holds.** Host env: `APP_ENV=production`, `APP_DEBUG=false`, `LOG_LEVEL=warning`, `SESSION_SECURE_COOKIE=true`. Security headers on every response.
- **A06 — PASS with a waiver.** `composer audit`: no advisory. `vendor-audit --gate` (OSV.dev, 231 components): six advisories on `vite` 8.2.2 (1 High, 4 Medium, 1 Low), all in the dev server's `launch-editor` on Windows. Waived by the owner for this release (decision `631b5ca1b1568830`): the host serves pre-built assets and never runs vite. Bump to 8.2.4 in 3.0.1.
- **A07 — new surface, holds.** CSRF-protected sign-in, session regenerated, generic error, 12-character minimum, forced first change, no remember-me cookie, sign-out ends the session.
- **A08 — no change.** Deploys pull `main` over HTTPS; no webhook token in the repository.
- **A09 — no change.** Laravel daily logs at `warning`; Cipi records every deploy in its hash-chained ledger.
- **A10 — closed.** The app makes no outbound HTTP request any more.

CI checks run locally on the release: 451 tests, Pint, Larastan — all pass.

## Findings

### [Low] Empty-password first sign-in after the deploy

- **OWASP:** A07
- **Location:** `database/migrations/2026_10_26_201636_add_username_to_users_table.php`, `POST /login`
- **Risk:** until the owner sets a password, whoever reaches `/login` can set it. Accepted on 2026-10-18; mitigated on the host by Cipi basic auth.
- **Remediation:** sign in as `giarfa` and set the password immediately after unsuspending.

### [Low] One-off cache flush at migration

- **OWASP:** A04
- **Location:** `database/migrations/2026_10_26_210040_remove_strava_from_schema.php`
- **Risk:** the login and import throttle counters restart from zero once.
- **Remediation:** none needed.

### [Info] Host hygiene

- Leftover `STRAVA_*` keys in the host env — removed at deploy.
- Cipi scheduler left on by the owner's choice; it runs no task.

### [Info] Accepted risks unchanged

- `SECURITY.md` and `security.txt` deferred while the instance is private.

## Ship Recommendation

**GO.** No Critical or High finding in the application; the only High in the dependency gate is waived with a recorded reason. Deploy, unsuspend, and set the owner password at once.
