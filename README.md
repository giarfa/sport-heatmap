# Progetto Larapilot

#### Passaggi già fatti

- composer create-project laravel/laravel larapilot
- cd larapilot && composer require andreapollastri/larapilot
- cd larapilot && php artisan larapilot:install
- cd larapilot && php artisan boost:install
- cd larapilot && php artisan migrate --seed

#### Passaggi da fare

- Avviare il progetto in locale con "php artisan serve"
- Usare Larapilot - qui degli esempi semplici: https://larapilot.web.ap.it/#examples (leggere il resto della guida)
